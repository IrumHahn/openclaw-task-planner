# 예제 — "홈페이지 만들고 싶어" (규모 중)

가상의 1인기업. 팀: 루미(총괄·전략·검토), 노바(콘텐츠 리서치·초안). 업무지도에 홈페이지 항목 없음.

## 과업 설계: 홈페이지 제작

- 출처: 사용자 "홈페이지 만들고 싶어"
- 이번 범위: 소개·서비스·연락 3페이지, 미리보기까지 (배포는 별도)
- 규모: **중** — 역할 3개(카피·디자인·구현), 산출물 의존(카피→디자인→구현). 반복 아님(Q3=0)
- 외부 부작용: 없음 (배포는 사용자 승인 후 별도 과업)

### 액션플랜

| # | 액션플랜 | 산출물 | 담당 | 칸 | 검수 |
|---|---|---|---|---|---|
| 1 | 페이지 구조·카피 | 3페이지 문안 .md | 노바 | 기존 | 루미 |
| 2 | 시안 | 데스크톱·모바일 시안 2장 | 디자이너 | 임시 | 루미 |
| 3 | 구현 | 로컬에서 열리는 HTML 3장 | 개발자 | 임시 | 노바 (링크·문안 대조) |
| 4 | 조립·전체 점검 | 미리보기 확인 기록 | 루미 | 기존 | 노바 — 독립 검수 아님 표시 |

### 인력

- **기존으로 됨**: 노바(카피), 루미(검수·조립)
- **임시(서브에이전트)**: 디자이너, 개발자 — 이 과업 끝나면 사라짐
- **정식 신설 권고**: 없음 — 홈페이지는 일회성
